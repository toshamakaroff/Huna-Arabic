# Хуна Аль-Арабия — Telegram Mini App

Статическое приложение: никакой сборки не нужно.

## Публикация
1. GitHub → New repository → Upload files → перетащить ВСЁ содержимое этой папки (не саму папку) → Commit.
2. Vercel → Add New → Project → Import этот репозиторий → Deploy. Настройки не трогать.
3. @BotFather → /newbot → затем /newapp (или Bot Settings → Menu Button) → вставить ссылку от Vercel.
   Аватарка бота: assets/bot-avatar.png

## Структура
- index.html, styles.css, app.js — приложение
- data/book1.js — содержимое тома 1 (главы, диалоги, слова)
- pages/ — страницы учебника (1–154)
- assets/ — логотип и аватарка
